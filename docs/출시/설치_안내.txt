공작소의 밤 — 설치 안내
========================

천천히 따라 하면 됩니다.
한 줄에 한 가지만 적었어요.
[ ] 안의 글자는 화면의 버튼 이름이에요.



------------------------
준비물
------------------------

- Windows 10 또는 Windows 11 컴퓨터
- 인터넷
- 빈 공간 1GB 정도



------------------------
1단계. 내려받기
------------------------

1.  받은 구글 드라이브 링크를 엽니다.

2.  파일 이름을 확인합니다.
    GongjaksoNight-Setup 으로 시작하는 파일이에요.

3.  오른쪽 위의 [다운로드] 를 누릅니다.

4.  "바이러스 검사를 할 수 없습니다" 가 뜰 수 있어요.
    파일이 커서 뜨는 말이에요. 괜찮아요.
    [무시하고 다운로드] 를 누릅니다.

5.  인터넷 창이 파일을 막을 수 있어요.
    ("흔히 다운로드되는 파일이 아닙니다" 같은 말)
    [보관] 또는 [유지] 를 누릅니다.



------------------------
2단계. 설치하기
------------------------

1.  내려받은 파일을 두 번 누릅니다.

2.  파란 창이 뜰 수 있어요.
    "Windows의 PC 보호"
    작은 팀이 만든 게임이라 뜨는 경고예요.

    -> [추가 정보] 를 누릅니다.
    -> [실행] 을 누릅니다.

3.  "이 프로그램의 사용자는 누구인가요?"
    그대로 두고 [다음] 을 누릅니다.

4.  설치할 폴더가 나와요.
    그대로 두고 [설치] 를 누릅니다.

5.  잠깐 기다립니다.
    1분이면 끝나요.

6.  마지막 화면이에요.
    "바탕화면에 바로가기 만들기"
    체크를 켜 두면 찾기 쉬워요.

7.  [마침] 을 누릅니다.



------------------------
3단계. 게임 켜기
------------------------

바탕화면의 "공작소의 밤" 을 두 번 누릅니다.

바탕화면에 없으면:
시작 버튼을 누르고 "공작소" 라고 쳐 보세요.

소리를 켜고 하세요.
이어폰을 쓰면 더 무서워요.



------------------------
친구와 같이 하기
------------------------

[방을 만드는 사람]

1.  [온라인 멀티플레이] 를 누릅니다.
2.  닉네임을 씁니다.
3.  [인터넷 방 만들기] 를 누릅니다.
    처음에는 1분쯤 걸릴 수 있어요.
    서버가 잠에서 깨는 중이에요.
4.  화면에 방 코드 4글자가 나와요.
    친구들에게 알려 줍니다.

[들어가는 사람]

1.  [온라인 멀티플레이] 를 누릅니다.
2.  닉네임을 씁니다.
3.  [참가하기] 칸에 방 코드 4글자를 씁니다.
4.  [접속] 을 누릅니다.

이야기는 디스코드 음성방에서 같이 해요.



------------------------
업데이트
------------------------

따로 할 일은 없어요.
새 버전이 나오면 게임이 알아서 받아요.

화면 오른쪽 아래에 안내가 뜨면
[지금 재시작] 을 누르면 끝이에요.



------------------------
게임을 지우고 싶을 때
------------------------

1.  Windows [설정] 을 엽니다.
2.  [앱] 을 누릅니다.
3.  "공작소의 밤" 을 찾습니다.
4.  [제거] 를 누릅니다.

저장한 기록은 지워지지 않아요.



------------------------
안 될 때
------------------------

설치 창이 안 떠요.
-> 파일을 한 번 더 두 번 눌러 보세요.
-> 그래도 안 되면 컴퓨터를 다시 켜고 해 보세요.

인터넷 방이 안 만들어져요.
-> 1분 기다렸다가 다시 눌러 보세요.

그래도 안 되면
화면 사진을 찍어서 디스코드에 물어봐 주세요.
