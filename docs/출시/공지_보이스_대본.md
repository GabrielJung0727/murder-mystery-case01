# 출시 공지 보이스 — 대본과 연출

**길이:** 40초 안팎
**파일:** `공지_보이스.mp3` (디스코드 공지에 첨부)
**목소리:** 게임 나레이터와 같은 사람(같은 보이스)이면 가장 좋아요. 게임을 켰을 때 "아, 그 목소리" 하게 됩니다.

## 톤

- 낮고 느리게. 속삭이듯, 하지만 또렷하게.
- 겁주려고 소리 지르지 않기. **조용할수록 무섭습니다.**
- 문장 끝은 내려 말하기. 질문도 끝을 올리지 않기.
- 1부는 사건 현장을 보고하는 목소리, 2부는 듣는 사람에게 직접 말을 거는 목소리.

> TTS로 만든다면: 안정성(stability)은 낮게, 말 속도는 0.85~0.9배.
> 한 번에 다 만들지 말고 아래 덩어리별로 만들어 이어 붙이면 쉬는 타이밍을 맞추기 쉬워요.

## 대본

`/` = 짧게 쉬기 (0.5초) · `//` = 길게 쉬기 (1.5초) · `( )` = 연출 메모

### 1부 — 그날 밤 (약 15초)

(빗소리, 시계 초침만)

> 새벽 1시 3분. //
> 방 문이 / 열렸다. //
> 누군가가 / 쓰러져 있었다. //

(초침 소리 세 번)

> 펜션에 남은 사람들. /
> 모두 / 무언가를 / 숨기고 있다.

### 2부 — 초대 (약 20초)

(음악이 아주 낮게 들어온다)

> 당신은 / 수사관이 될 수도 있고, /
> 그들 중 / 한 명이 될 수도 있다. //
> 그리고 / 범인은, / 매번 같지 않다. //
>
> 공작소의 밤. /
> 지금, / 그 밤의 기록이 열렸다.

### 3부 — 마지막 한 마디 (약 5초)

(음악 멈춤. 빗소리만.)

> 불을 끄고, / 이어폰을 껴. //

(속삭이듯, 아주 가까이)

> ……누가 거짓말을 하고 있지?

(1초 정적으로 끝)
