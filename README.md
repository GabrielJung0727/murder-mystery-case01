# 공작소의 밤 — MURDER MYSTERY CASE 01 (PC)

`docs/`의 원작 시나리오(이선빈 범인 편)를 순수 2D UI로 옮긴 독립 실행형 PC 게임입니다.
Electron + React + TypeScript로 만들었고, 싱글 플레이와 5인 온라인 플레이를 하나의 앱에서 지원합니다.

## 실행

```bash
npm install
npm run dev        # Electron 개발 실행 (Vite + Electron)
npm run dist       # release/GongjaksoNight-Setup-<버전>.exe (설치형) + latest.yml (자동 업데이트용)
npm run e2e:online # 실제 호스트 서버로 5인 온라인 한 판을 끝까지 돌리는 통합 테스트
npm test           # 엔진·서버 테스트
```

`npm run dev:web`으로 브라우저에서도 실행할 수 있습니다. 브라우저는 방을 열 수 없으므로, 온라인 테스트는
`npm run server`(호스트 토큰 `dev-host`)를 먼저 실행한 뒤 "참가하기"에서 `localhost:4777`로 접속합니다.

## 모드

| 모드 | 내용 |
|---|---|
| 싱글 · 수사관 | 5명 전원이 NPC. 라운드마다 2곳을 조사하고, 나머지 카드는 NPC가 가져갑니다. NPC는 자신에게 불리한 카드를 숨깁니다. |
| 싱글 · 이성철 시점 | 이성철로 플레이하고 나머지 4명을 심문합니다. |
| 싱글 · 해금 시점 | 엔딩을 한 번 본 뒤 정재구·남여진·김아린 시점이 열립니다. 이선빈(진범)은 싱글에서 제공하지 않습니다. |
| 온라인 5인 | 한 명이 "방 만들기"로 호스트가 되고 나머지는 `IP:포트`로 접속합니다. 음성 대화는 디스코드 등을 함께 사용합니다. |

온라인 접속: 같은 공유기 안에서는 호스트 화면에 표시된 주소로 바로 접속할 수 있습니다. 외부 친구와 하려면
공유기 포트포워딩(기본 4777/TCP)이나 Tailscale·ZeroTier 같은 가상 LAN이 필요합니다. 첫 실행 때 Windows 방화벽
허용 창이 뜨면 허용해야 합니다.

## 구조

```
src/data      원작 데이터 (카드 35장, 인물 5명, 엔딩·낭독문, NPC FSM 스크립트, 스마트폰 표시용 데이터)
src/engine    순수 상태 머신: applyAction(state, action) — 싱글과 온라인 호스트가 같은 엔진을 사용
src/net       호스트 권위 서버 (WebSocket). 좌석은 서버가 판정하고, 좌석별로 필터링된 상태를 전송
src/client    온라인 접속 훅, Electron 브리지
src/ui        3단 대시보드 (평면도 / 코르크 보드·타임라인 / 스마트폰·심문·기록), 보고서, 엔딩·아카이브
electron      메인 프로세스 (호스트 서버 시작·중지), preload
```

## 원작에 없어서 개발 측에서 정한 규칙

- **NPC 투표 (싱글):** 이선빈이 자백했으면 전원이 이선빈에게 투표합니다. 자백 전에는, 무고한 NPC는 자기 방어선이
  완전히 무너졌고 이선빈이 동기를 인정한 상태이거나 14·31·34 중 2장 이상이 공개됐으면 이선빈에게 투표합니다.
  그 외에는 공개된 증거 기준으로 가장 의심스러운 인물에게 투표합니다. 엔딩 A의 기준은 투표자 과반입니다(5명이면 3표).
- **FSM 명세 병합:** 2장 반응표를 기준으로 하고, 4장 JSON의 강제 공개 카드와 1.1의 은폐 해제 조건을 합쳤습니다.
  정재구에게 증거 26을 먼저 제시하는 경우처럼 표에 없는 대칭 반응은 보완했습니다. 시뮬레이션 테스트에서 모든
  싱글 시점이 95% 이상의 시드에서 자백까지 도달 가능합니다.
- **개인 목표 보너스 자동 판정:** 각 인물 서류철의 "개인 목표" 끝 괄호에 판정 기준을 적어 두었습니다.
- **최종 보고서:** 범인·동기·시간·수법은 필수입니다. 증거 연결은 선택이며, 2장 이상일 때만 1점을 줍니다.
  확보한 카드가 1장 이하인 플레이어도 제출할 수 있게 하기 위해서입니다.

## 비주얼

- 빗줄기 캔버스, 필름 노이즈, 비네트를 겹친 분위기 레이어(`src/ui/Atmosphere.tsx`)를 씁니다. 타이틀은 진하게 깔고 번개도 넣었으며, 대시보드는 가독성을 위해 옅게 깝니다.
  OS에서 "애니메이션 줄이기"를 켜면 빗줄기와 노이즈 움직임이 멈춥니다.
- 글꼴은 오프라인에서도 보이도록 앱에 포함했습니다(@fontsource, SIL OFL 라이선스). Special Elite(영문 타자기),
  나눔고딕코딩(단말기·숫자), 나눔명조(제목), 나눔손글씨 펜(손글씨 메모)을 사용합니다.
- 강조색은 핏빛 레드이고, 평면도만 차가운 청사진 블루를 씁니다.

## 메인 메뉴

사건 파일 두 장(싱글·온라인)이 게임 시작 버튼입니다. 그 아래에 설정(소리·전체 화면·UI 배율·화면 효과), 갤러리 & 다시보기,
사건 기록실(크레딧, `src/data/credits.ts`), 게임 종료(exe 전용) 버튼이 있습니다.

갤러리는 싱글·온라인을 가리지 않고, 한 번이라도 본 증거 카드와 도달한 엔딩을 PC에 기록합니다(`src/client/progress.ts`).
아직 보지 못한 카드와 엔딩은 봉인 상태로 표시합니다. 진행자 해설과 사건의 진상은 엔딩을 한 번 본 뒤에 열립니다.

## 알려진 한계

- 내장 음성 채팅(WebRTC)은 아직 없습니다.
- 카드 원문은 클라이언트에 포함되어 있습니다. 손패 은폐는 UI 규칙으로 지키며, 악의적인 개발자 도구 조작까지 막지는 않습니다.
- 환경음, 결과 화면 모션 그래픽 같은 연출 폴리싱은 기본 수준입니다.

## 배포와 자동 업데이트

- 설치형(NSIS): 설치 폴더 선택, 바탕화면·시작 메뉴 바로가기, 제거 기능. 제거해도 저장 기록(`%APPDATA%\공작소의 밤`)은 남는다.
- 자동 업데이트(electron-updater): 실행 4초 뒤 GitHub 최신 릴리스를 확인해 뒤에서 받고, 화면 구석 [지금 재시작] 또는 게임 종료 때 설치한다.
  확인 기록은 `%APPDATA%\공작소의 밤\update.log`.
- 새 버전 내는 법: `package.json` 버전을 올리고 `npm run dist` → GitHub 릴리스에 **`Setup-<버전>.exe`, `.blockmap`, `latest.yml` 세 파일을 모두** 올린다.
  `latest.yml`이 없으면 기존 사용자에게 업데이트가 뜨지 않는다.
- 업데이트 동작 시험: 로컬에서 새 버전 파일 세 개를 http로 띄우고 `GONGJAKSO_UPDATE_URL=http://127.0.0.1:포트/` 환경 변수로 설치된 게임을 실행한다.

## 온라인 플레이 (다른 장소)

포트포워딩 없이, 6명이 같은 와이파이에 있는 것처럼 접속하는 방법입니다. 무료입니다.

1. **모두:** [tailscale.com/download](https://tailscale.com/download)에서 Tailscale을 설치하고 로그인합니다.
2. **호스트:** Tailscale 관리 화면([login.tailscale.com/admin](https://login.tailscale.com/admin))에서 **Invite users**로 친구들을 초대합니다. 초대받은 친구는 메일의 링크로 들어옵니다.
3. **호스트:** 게임에서 **방 만들기**를 누르면 대기실에 접속 주소가 여러 개 뜹니다. 그중 **`100.`으로 시작하는 주소**(예: `100.84.12.7:4777`)를 친구들에게 알려 줍니다.
4. **친구:** **참가하기**에서 그 주소를 입력합니다.

- 처음 방을 열 때 Windows 방화벽 창이 뜨면 **허용**(개인 네트워크)을 눌러 주세요.
- 접속이 안 되면 모두의 Tailscale 아이콘이 **Connected**인지 확인하세요.
- Tailscale 무료 플랜은 **6명까지**입니다(5인 게임은 충분). 그보다 많으면 초대 대신 호스트 PC를 **Share**(기기 공유)로 보내면 인원 제한 없이 접속할 수 있습니다.

## 다시 하는 재미 (v2.2)

- **진범 변형:** 같은 인물·펜션·증거 사진으로 진범과 동기가 바뀐다. `src/data/variants.ts`
  - 사건 기록 A 「사의」 = 원작 (이선빈), B 「약속의 시간」 (이성철), C 「오랜 친구」 (정재구).
  - 변형에서는 이선빈의 푸른 흔적이 숨긴 자정 외출이 되어 붉은 청어가 된다. 사망 시각·수법·증거 01/02/35는 공통.
  - 카드 본문·해설, 인물 비밀, NPC 심문 대사, 타임라인 진술, 엔딩·진상이 변형별로 덮어써진다 (`src/data/caseData.ts` 가 합친다).
  - 싱글은 플레이어 본인이 진범인 변형을 고르지 않는다. 온라인은 호스트가 대기실에서 사건 선택(원작/변형/완전 무작위)을 정하고, 시작할 때 변형이 정해진다.
  - 엔딩·진상 나레이션 녹음은 원작 본문이라 변형에서는 D 엔딩만 읽는다.
- **어려움 모드:** 단서 힌트 없음, 심문 단계마다 증거 제시 5회, NPC가 자기에게 불리한 증거를 더 숨김, 타임라인 판정은 엔딩에서 공개, 랭크 +1.
- **역할별 개인 목표:** 인물마다 3개 (진범을 맡으면 진범용 3개, 수사관도 3개). 달성할 때마다 +1점. `src/data/goals.ts`
- **랭크·도전 과제:** 판마다 S~D 랭크, 18개 도전 과제와 사건 기록별 최고 랭크를 갤러리 [기록·도전 과제]에 저장. `src/data/achievements.ts`
- 변형마다 싱글 시점별로 '성실한 플레이어'가 자백까지 가는지 시뮬레이션으로 검증한다 (`src/engine/variants.test.ts`, 95% 이상).
