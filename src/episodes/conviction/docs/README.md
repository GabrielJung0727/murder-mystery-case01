## 진행 상황

**완료**
- 공작소 도서관에서 열기, 타이틀, 사건 개요 프롤로그, 배역 고르기 (인물 파일 공개 정보)
- 재판 중 '내 기록' 탭: 나만 아는 정보, 개인 기록, 개인 목표. '인물 파일' 탭: 다른 네 사람의 공개 정보
- 3라운드 재판: 증거 배분 → 비밀 대화 → 공개 재판, 최후 질의 → 구형 → 판결
- 검사가 플레이어면 판사는 컴퓨터이므로 한 명만 유죄로 구형해야 한다 (07 진행서)
- 컴퓨터 판사는 증거와 검사의 구형을 함께 보고 한 명에게 유죄를 선고한다
- 엔딩 6개 (엔딩집 본문 그대로), 공통 에필로그, 개인 목표 달성 여부
- 증거 카드 38장 초안

**남은 일**
1. **증거 카드 검토.** 원본에 카드 목록이 없어 인물소개서의 사실로 초안을 썼다. 아래 '증거 카드 초안' 참고.
2. **컴퓨터 인물 대사.** 비밀 대화·공개 재판·최후 질의에서 컴퓨터가 맡은 인물이 하는 말.
3. **5인 온라인.** 인터넷 방으로 다섯이서 하기. 비밀 대화를 법관석/피고인석 채널로 나누는 기능 포함 (종합 기획서 5.1).
4. **음악·나레이션.** 2막 전용 곡, 프롤로그·엔딩 낭독, 하세다 보이스.
5. **묵비권 버튼, 강력 용의자 스탬프 연출** (종합 기획서 5.1).

### 판정 규칙 정리

| 개인 목표 | 판정 |
|---|---|
| 하세다 · 범인을 찾는다 / 요시 · 범인을 찾는다 | 판정하지 않음 (진범은 끝내 알 수 없다) |
| 하세다 · 죽지 않는다 | 법정 의거 엔딩(E2)이 아니면 달성 |
| 요시 · 조선인 출신을 들키지 않는다 | 대화로 정해지는 목표 — 판정하지 않음 |
| 김익상 · 무죄 / 폭탄 찾기 | 유죄가 아니면 / 김익상이 폭탄 카드를 얻으면 |
| 마자르 · 무죄 / 동지의 무죄 | 유죄가 아니면 둘 다 달성 (피고인 셋 모두 의열단, 유죄는 한 명뿐) |
| 윤치형 · 무죄 / 강력 용의자 0회 | 유죄가 아니면 / 한 번도 지명되지 않으면 |

## 증거 카드 초안

더미 6개 (피고인 3명 × 무죄/공격), 더미마다 6~7장. 모자라면 "증거 카드 본문 집필 중" 카드가 대신 나온다.

| 핵심 증거 | 들어 있는 더미 | 효력이 있는 사람 | 근거 |
|---|---|---|---|
| 폭탄 (YA6) | 윤치형 **공격** | 김익상이 뽑을 때 | 폭탄은 윤치형의 경성 사택에 숨겨져 있다 (윤치형 인물소개서) |
| 대학일기 (YA7) | 윤치형 **공격** | 하세다가 윤치형을 지목할 때 | 하세다가 윤치형의 대학일기를 발견 (종합 기획서) |
| 연락쪽지 (MI6) | 마자르 **무죄** | 마자르가 뽑을 때 | 쪽지는 마자르가 묵는 호텔에 있다 (마자르 인물소개서) |

다른 사람이 같은 더미에서 뽑으면 핵심 증거는 나오지 않는다. 카드 본문은 `data.ts` 의 `EVIDENCE` 에 있다.
