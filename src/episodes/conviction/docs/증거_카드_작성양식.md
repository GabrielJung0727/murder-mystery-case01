# 증거 카드 작성 양식

지금 게임에는 인물소개서를 바탕으로 쓴 초안 38장이 들어 있습니다 (`data.ts` 의 `EVIDENCE`, 목록은 README 참고).
고치거나 더할 카드를 아래 칸에 맞춰 적어 주세요.

| 칸 | 쓰는 법 |
|---|---|
| 번호 | 지금 카드를 고칠 때는 그 번호(예: `KA3`), 새 카드는 비워 두기 |
| 종류 | **무죄** (그 피고인이 무죄라는 증거) 또는 **공격** (그 피고인을 공격하는 증거) |
| 대상 | 마자르 / 윤치형 / 김익상 |
| 제목 | 카드 앞면 제목 (짧게) |
| 본문 | 카드에 적힌 내용 |
| 핵심 | 폭탄 / 대학일기 / 연락쪽지 중 하나일 때만 적기 |

## 필요한 장수 (참고)

한 판에 뽑히는 수: 피고인 3명 × 3번 × 3라운드 = 27번, 검사 2장 × 3 = 6장, 판사 1장 × 3 = 3장, 강력 용의자 보너스 최대 2장.

더미는 6개입니다 (피고인 3명 × 무죄/공격). 더미마다 **6장 이상** 있으면 같은 판에서 카드가 모자라지 않습니다. 모자라면 "증거 카드 본문 집필 중" 카드가 대신 나옵니다.
